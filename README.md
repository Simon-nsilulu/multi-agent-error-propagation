# Распространение непреднамеренных ошибок агентов: численная иллюстрация

Программный код к статье:

> Нсилулу С.Н., Каширина И.Л. Оценка распространения непреднамеренных ошибок агентов при формировании коллективного решения в мультиагентных системах (статья направлена в журнал «Управление большими системами»).

Код воспроизводит расчёты раздела 8: таблицу 1 (статистическая иллюстрация для обобщённой медианной схемы) и проверку полным перебором на конечных сетках.

## Требования

- Python ≥ 3.9
- NumPy (`pip install -r requirements.txt`)

Расчёты в статье выполнены на Python 3.11 и NumPy 2.x.

## Запуск

```bash
python simulation.py        # таблица 1, около 1 минуты
python exhaustive_check.py  # полный перебор, несколько секунд
```

## Что вычисляется

`simulation.py` — n = 5 агентов, m = 0, 10 000 испытаний в каждом из четырёх сценариев, seed = 2026. Значения rᵢ ~ U[0, 1], Aᵢ = ℝ (сообщения не усекаются). Для каждого испытания вычисляются фактическое изменение |π(s) − π(r)|, минимальная по i правая часть оценки (8), тривиальная оценка (9) ‖e‖∞ и итоговая оценка (11); оценка (8) проверяется для каждого агента (50 000 проверок на сценарий). Результат сохраняется в `results/table1.csv`.

| Показатель | Сц. 1 | Сц. 2 | Сц. 3 | Сц. 4 |
|---|---|---|---|---|
| Среднее \|π(s) − π(r)\| | 0,072 | 0,036 | 0,040 | 0,100 |
| Среднее значение оценки (8) | 0,167 | 0,085 | 0,078 | 0,172 |
| Среднее значение оценки (9) | 0,500 | 0,079 | 0,063 | 0,123 |
| Среднее значение оценки (11) | 0,167 | 0,076 | 0,062 | 0,123 |
| Доля испытаний, где (8) строже (9) | 80,5 % | 9,9 % | 5,4 % | 5,0 % |

Нарушений оценок (8) и (11) нет. В сценарии 1 оценка (8) достигается точно в 27,3 % испытаний.

`exhaustive_check.py` — n ≤ 4, m ≤ 2, N нечётно, N ≥ 3, rᵢ ∈ {0,1,2,3}, aⱼ ∈ {0,1,2}, eᵢ ∈ {−3,−1,0,1,3}, Aᵢ = ℝ. Проверено 561 380 вариантов (2 162 580 проверок оценки (8)): нарушений (8) и (11) нет; оценка (8) строже (9) ровно в тех вариантах, где выполнено условие (10).

Сохранённые выводы обоих скриптов находятся в папке `results/`.

## English summary

Code accompanying the paper by S.N. Nsilulu and I.L. Kashirina on bounding the propagation of unintentional agent errors in collective decisions (generalized median scheme). `simulation.py` reproduces Table 1 (seed 2026); `exhaustive_check.py` runs the exhaustive grid check of bounds (8), (11) and condition (10).
